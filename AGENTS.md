# Instruções do projeto

- Sempre que o usuário pedir "commit", encaminhe a execução ao terminal responsável pelos commits no Maestri, usando a skill `maestri`. Não execute o commit diretamente neste agente.
- Informe ao terminal quais alterações pertencem ao pedido e preserve alterações alheias. Fazer commit não autoriza push; encaminhe push somente quando o usuário também o solicitar.
